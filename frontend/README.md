# Nucleus AI Search Engine — Web Portal

Modern React & TypeScript Web Dashboard for **Nucleus** (Self-Hosted Enterprise AI Search Engine).

## Features

- **Glean-Style Hybrid RAG Search Portal**
- **Multi-Tenant Persona & Access Control Switcher** (Intern, Eng Lead, HR Manager)
- **Anti-Hallucination Citation Viewer** (`[Doc_ID]`)
- **SOC2 Append-Only Audit Log Inspector**
- **Air-Gapped Ed25519 License Gate Activator**

## Development

```bash
npm install
npm run dev
```

## Built with

- TanStack Router & TanStack Query
- React 19 & TypeScript
- Tailwind CSS & Radix UI
- Lucide Icons & Motion
